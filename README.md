# Synthex AE Macro

A macro made for **Anime Expeditions** on Roblox.

Synthex AE is built to automate different gamemodes while giving you control over layouts, tasks, settings, and more through a clean GUI.

> This repository is used for releases and downloads. The source code is not public.

## Features

- Story Mode
- Raid Mode
- Expedition Mode
- Event Mode
- Tower Mode
- Automatic unit placement
- Custom layouts
- Task queue
- Customizable hotkeys
- Multi-resolution support
- Expedition encounter handling
- Automatic reward card selection
- Custom themes and appearance settings
- Start and Stop controls
- Performance options

## Download

Download the latest version from the **Releases** section of this repository.

**Do not download AE Macro from random reuploads or unofficial links.**

## Installation

1. Download the latest release.
2. Extract the ZIP file.
3. Keep all included files and folders together.
4. Open the AE Macro executable.
5. Configure your tasks and settings.
6. Start the macro.

## Custom Layouts

AE Macro supports custom unit layouts.

You can create a layout for supported gamemodes directly through the Layout Editor.

Follow the instructions shown inside the editor and use your configured hotkeys to walk the required path and save unit positions.

## Supported Resolutions

Use 1920x1080 for the best experience

AE Macro includes multi-resolution support.

For the best experience, make sure Roblox and your display settings are configured correctly.

## Bug Reports

Found a bug?

Please report it in the Synthex Discord server and include as much information as possible:

- Gamemode
- Map and Act
- Selected difficulty
- Your screen resolution
- What happened
- What you expected to happen
- Screenshot or video if possible
- Console/log output if available

Detailed reports make bugs much easier to reproduce and fix.
